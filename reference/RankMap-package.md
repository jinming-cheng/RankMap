# RankMap: Rank-based reference mapping for fast and robust cell type annotation in spatial and single-cell transcriptomics

RankMap is a fast and scalable tool for reference-based cell type
annotation of single-cell and spatial transcriptomics data. It uses
ranked gene expression and multinomial regression to achieve robust
predictions, even with partial gene coverage. Compatible with Seurat,
SingleCellExperiment, and SpatialExperiment objects, RankMap offers
flexible preprocessing and significantly faster runtime than tools like
SingleR, Azimuth, and RCTD.
